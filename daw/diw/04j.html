Ejemplos de Propiedades de Dimensionamiento

width (Ancho Fijo)

Este div tiene width: 250px; - Tiene un ancho fijo de 250 píxeles sin importar el contenido.

min-width (Ancho Mínimo)

Este div tiene min-width: 300px; - Nunca será más estrecho de 300 píxeles, pero puede crecer si el contenido es más grande.

max-width (Ancho Máximo)

Este div tiene max-width: 400px; - Nunca superará los 400 píxeles de ancho. Si el contenido es más pequeño, se encogerá. Esta es una propiedad muy utilizada para diseño responsivo.

height (Altura Fija)

Este div tiene height: 150px; - Tiene una altura fija de 150 píxeles. Si el contenido ocupa más espacio, aparecerá overflow (el contenido se saldrá de la caja).

min-height (Altura Mínima)

Este div tiene min-height: 100px; - La altura mínima es 100 píxeles, pero crecerá si el contenido lo requiere.

max-height (Altura Máxima)

Este div tiene max-height: 120px; - La altura máxima es 120 píxeles. Si el contenido es más alto, aparecerá una barra de desplazamiento (scroll). Este contenido contiene varias líneas para demostrar cómo funciona el overflow cuando el contenido supera la altura máxima.

Combinación: min-width y max-width (Responsivo)

Este div tiene min-width: 200px; y max-width: 600px; - Esto significa que el ancho nunca será menor a 200px ni mayor a 600px. Esta es una técnica común para diseño responsivo que se adapta entre estos límites.

Combinación: min-height y max-height

Este div tiene min-height: 80px; y max-height: 200px; - La altura está limitada entre 80 y 200 píxeles. Si el contenido excede 200px, aparecerá scroll.
